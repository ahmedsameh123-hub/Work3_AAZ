## 📌 Standard Guidelines for Team Folders (For Adham & Zyad)

To ensure the entire repository stays cohesive and ready for seamless integration into our agency website, follow the folder structure established in `Web_Ahmed/`:

1. **Flutter Projects (`01_Flutter_Projects/`)**:
   - Store application source code alongside a detailed `README.md` covering architecture, dependencies, and setup.
   - Include high-resolution screenshots in a dedicated screenshots folder.
2. **Web Projects (`02_Web_Projects/`)**:
   - Provide clean source code with links to deployed live demos.
3. **Certifications (`04_Certificates_and_Credentials/`)**:
   - Store official PDF credentials or digital badge images with clean, URL-safe naming.
4. **Screenshots & Media (`05_Screenshots_and_Media/`)**:
   - Organize web previews, mobile screenshots, and profile branding assets.

## 🛠️ GitHub Workflow

The repository is equipped with a comprehensive `.gitignore` that prevents bulky virtual environments (`.venv`), Flutter build outputs (`build/`, `.dart_tool/`), and `node_modules` from cluttering Git history.

To commit and push updates:
```bash
git add .
git commit -m "Organize Web_Ahmed portfolio hub, add screenshots, live links, and comprehensive documentation"
git push origin main
```
