## 🏋️‍♂️ Graduation Project: TrainMate — AI-Powered Smart Gym Assistant

TrainMate is an advanced cross-platform mobile application that combines **on-device real-time pose tracking & rep counting via the phone camera**, **personalized workout plans**, an **AI-powered fitness chatbot**, and **body progress analysis (before/after photo comparison)**.

### 👥 Engineering Team & Ahmed Sameh's Role:
- **Ahmed Sameh**: Lead Flutter Mobile Developer + Machine Learning model training & on-device TFLite inference pipeline.
- **Adham Allam**: Flutter Mobile App + Exercise Classifier.
- **Ahmed Wael**: AI Fitness Chatbot (Groq / OpenRouter integration).
- **Ibrahim Mohamed**: Live Form Feedback & Rep Counting + Body Comparison.
- **Amira Yasser**: FastAPI Backend Server & Database Architecture.
- **Supervisor**: Associate Professor Mohamed Ghetas.

---

## 🛠️ Technology Stack
- **Mobile Frontend**: Flutter 3 (Dart), Provider / BLoC State Management, Camera Streaming, TensorFlow Lite (TFLite).
- **AI & Computer Vision**: MediaPipe Pose Landmark Detection, TensorFlow / Keras, Custom Exercise Classifier.
- **Backend & Database**: Python FastAPI, SQLAlchemy, SQLite/PostgreSQL, JWT Authentication.
- **AI Cloud Services**: Groq LLaMA / OpenRouter APIs for conversational fitness coaching.
