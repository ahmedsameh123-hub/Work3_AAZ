# خدمة خمسات — انسخ والصق

التصنيف: برمجة وتطوير ← تطوير المواقع / إنشاء موقع إلكتروني  
السعر المقترح للبداية: 5$ أو 10$  
مدة التسليم: 3 أيام  
عدد التعديلات: 2

## العنوان

تصميم وبرمجة صفحة هبوط احترافية متجاوبة HTML CSS JS

## الكلمات المفتاحية

صفحة هبوط، تصميم موقع، HTML، CSS، JavaScript، موقع متجاوب، لاندنج بيج، فرونت اند

## وصف الخدمة

أصمم وأبرمج لك صفحة هبوط (Landing Page) احترافية ومتجاوبة مع الموبايل باستخدام HTML وCSS وJavaScript.

شوف أمثلة شغلي الحية:
- البورتفوليو: https://ahmedsameh123-hub.github.io/ahmed-sameh-portfolio/
- Easybank: https://ahmedsameh123-hub.github.io/ahmed-sameh-portfolio/projects/easybank/
- Fiber: https://ahmedsameh123-hub.github.io/ahmed-sameh-portfolio/projects/fiber/
- MovieBox: https://ahmedsameh123-hub.github.io/ahmed-sameh-portfolio/projects/moviebox/

### المشمول في السعر
- صفحة واحدة حتى 5 أقسام (هيرو، خدمات، عنّا، آراء، تواصل)
- تصميم متجاوب (كمبيوتر + موبايل)
- فورم تواصل بسيط
- تسليم ملفات المشروع كاملة
- تعديلين بعد التسليم

### غير مشمول (يُطلب كتطوير)
- صفحات إضافية
- ربط دومين أو استضافة
- لوحة تحكم / قاعدة بيانات / متجر كامل

أرسل لي: اسم النشاط، الألوان أو اللوجو إن وجد، والنصوص. أسلّم كود نظيف جاهز للرفع.
