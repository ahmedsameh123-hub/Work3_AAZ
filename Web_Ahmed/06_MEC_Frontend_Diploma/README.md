# 🎓 Front-End Web Development Diploma — MEC Academy

Practical training archives, weekly assignments, and code repositories from the intensive 18-week Front-End Web Development Professional Diploma at MEC Academy.

---

## 📅 Weekly Curriculum & Practical Labs

| Timeline | Core Technology | Practical Applications & Labs |
|---|---|---|
| **Weeks 1 - 3** | Web Architecture & Structure (HTML & HTML5) | Structuring accessible web pages adhering to Semantic HTML standards |
| **Weeks 4 - 6** | Modern Styling & Responsive Layouts (CSS & CSS3) | Implementing responsive UI designs with CSS Flexbox and CSS Grid |
| **Weeks 7 - 9** | Client-Side Scripting & DOM (JavaScript Basics) | Event-driven programming, DOM manipulation, and interactive form validation |
| **Weeks 10 - 12** | Advanced Modern JavaScript (ES6+, Async/Await & APIs) | Consuming RESTful web services via Fetch API, handling asynchronous data |
| **Weeks 13 - 15** | UI Component Architecture (React Basics & Hooks) | Component-based development, state and prop management, custom hooks |
| **Weeks 16 - 18** | Capstone Projects & Production Deployment | Developing an end-to-end cinema app (`React_Movie_App`) and developer portfolio |
